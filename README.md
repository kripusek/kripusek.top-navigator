# kripusek.top navigator

A simple website that acts as a navigation page for my projects and other stuff hosted under **kripusek.top**.

The idea is to have one place where I can quickly link to my software, hardware projects, websites, experiments, and anything else I make.

I was inspired by how mitxela (mitxela.com) did his website.

## Live website

https://kripusek.top

## Features

- Simple project navigation
- Separate categories for different types of projects
- Responsive layout
- Custom CSS styling
- Easy to expand by adding more links
